# Statistical Computing in R

Live page: https://afolabi-adesina-m.github.io/NA-Skills-Portfolio/projects/r-analytics/

## What this is

A professional skills showcase of **14 applied R problems** synthesized from an Analytics Edge materials folder (unit `.R` scripts, CSVs, and lecture themes): linear/logistic regression, CART & random forests, text mining, clustering, ggplot2 visualization, and linear optimization.

## Data & copyright

- Sample R snippets are **original illustrative demos**, not verbatim course solutions.
- Proprietary course datasets and assignment text are **not redistributed**.
- Charts and numeric callouts use **synthetic or public-style recreations** of typical patterns from these problem classes.
- Source materials were read locally for topic identification only.
