Star schema

Three facts share plant and month. Sales also joins product. The browser report below uses fact_plant_month and fact_exception only.

DAX measures

Eight measures for the semantic model. OTIF and fill rate in the extract are already rates, so the measures weight them by orders. Freight per tonne uses inventory tonnes on the plant-month row, not a weighed shipment.

Orders

Orders = SUM ( fact_plant_month[orders] )

Order count on the plant-month fact.

OTIF %

OTIF % =
DIVIDE (
    SUMX ( fact_plant_month, fact_plant_month[otif] * fact_plant_month[orders] ),
    [Orders]
)

Order-weighted on-time in-full rate. A small plant does not count the same as a large one.

Fill rate

Fill Rate =
DIVIDE (
    SUMX ( fact_plant_month, fact_plant_month[fill_rate] * fact_plant_month[orders] ),
    [Orders]
)

Same weighting as OTIF, using the fill rate column.

Freight spend

Freight Spend = SUM ( fact_plant_month[freight_spend_cad] )

Freight dollars on the plant-month fact, in CAD as stored in the extract.

Freight per tonne

Freight per Tonne =
DIVIDE (
    [Freight Spend],
    SUM ( fact_plant_month[inventory_tons] )
)

Freight spend divided by inventory tonnes on the same rows. It is not a cost per tonne shipped.

Sales

Sales = SUM ( fact_plant_month[sales_cad] )

Sales dollars on the plant-month fact.

OTIF vs target

OTIF vs Target pp = [OTIF %] - 0.95

Gap to a 95% OTIF target, in percentage points. The target is a label on this demo, not a contract.

Exception orders

Exception Orders = SUM ( fact_exception[order_impact] )

Orders touched by exception tickets in the filtered month and plant.
