# Python Skills Showcase

Live page: https://afolabi-adesina-m.github.io/NA-Skills-Portfolio/projects/python-skills/

## What this is

A professional skills showcase across **eight Sheridan PAIDA course modules**: advanced Python for AI/ML, data visualization, introduction to data science, big data analysis & storage, ethics & responsible AI, social media data mining, neural networks & deep learning, and AI & natural languages.

## Data & copyright

- Sample Python snippets are **original illustrative demos**, not verbatim course solutions.
- Proprietary course datasets and assignment text are **not redistributed**.
- Charts and numeric callouts use **synthetic recreations** of typical patterns from these skill areas.
- Source folders were explored locally for **topic identification** (chapter/lab titles) only.
