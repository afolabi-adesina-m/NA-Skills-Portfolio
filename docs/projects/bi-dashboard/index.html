Tableau extracts & publish path

Connect Tableau Public / Desktop to these files, then optional embed below.

  1. Open Tableau Public or Desktop.
  2. Connect to the CSVs under tableau/extracts/ (also mirrored in docs/assets/data/ for the web charts).
  3. Relate dim_plants → ops_control_tower / sales_by_category / otif_exceptions on plant.
  4. Build sheets: KPI cards, OTIF trend, regional bar, category treemap or bar, exception table, lane map from optimal_shipments.
  5. Publish to Tableau Public — live embed below uses the Minnesota Traffic Volume dashboard from this profile.
  • ops_control_tower.csv Plant-month OTIF, freight, turns, fill, sales, lat/lon
  • sales_by_category.csv Category / product-line revenue & units
  • otif_exceptions.csv Exception tickets, root cause, severity
  • regional_performance.csv Country–region rollups
  • dim_plants.csv Plant dimension (market, country, geo)
  • optimal_shipments.csv Network optimizer lanes for map overlays
