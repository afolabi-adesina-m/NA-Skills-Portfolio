## Local setup

```bash
python scripts/generate_data.py --sap-only
```

`python scripts/generate_data.py` also rebuilds the network and BI extracts. Open `docs/index.html` through a local static server. Root-absolute asset paths assume the `/NA-Skills-Portfolio/` base used on GitHub Pages.

## Tableau extracts

Connect Tableau Public or Desktop to `tableau/extracts/`:

| File | Contents |
|------|----------|
| `ops_control_tower.csv` | Plant-month OTIF, freight, turns, fill, sales, geo |
| `sales_by_category.csv` | Category and product-line revenue and units |
