## Local setup

```bash
python scripts/generate_data.py
```

Open `docs/index.html` via a local static server (or use GitHub Pages from `/docs` on `main`). Root-absolute asset paths assume the `/NA-Skills-Portfolio/` base used on GitHub Pages.

## Tableau extracts

Connect Tableau Public / Desktop to `tableau/extracts/`:

| File | Contents |
|------|----------|
| `ops_control_tower.csv` | Plant-month OTIF, freight, turns, fill, sales, geo |
| `sales_by_category.csv` | Category / product-line revenue & units |
| `otif_exceptions.csv` | Exception tickets with root cause & severity |
| `regional_performance.csv` | Country–region rollups |
| `dim_plants.csv` | Plant dimension (market, country, lat/lon) |
| `optimal_shipments.csv` | Network optimizer lane shipments |

The same CSVs are mirrored under `docs/assets/data/` for the interactive Plotly control tower.

## Data attribution

- **Primary:** Original synthetic North America ops / supply-chain / SAP MDM demo data generated by `scripts/generate_data.py` (seeded, portfolio-only).
- **Structural inspiration (not copied):** Office Training Hub Power BI practice layouts (region → market → store/plant style grain; historical sales field patterns) and Tableau study materials (dashboard hierarchy, calculated-field / LOD concepts, exception storytelling). Proprietary workbooks and datasets were not reproduced.
- No Kaggle download was required for this release; regenerate anytime with the script above.
